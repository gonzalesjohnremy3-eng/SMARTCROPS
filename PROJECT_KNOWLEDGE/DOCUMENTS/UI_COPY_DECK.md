---

## 1. Voice rules

- Use plain verbs and short sentences.
- Name the action, not the system.
- Keep the same verb through a flow.
- Explain what happened and what to do next.
- Use sentence case. No all-caps labels.
- Never overclaim. AI supports judgment; it does not replace an agronomist.
- Use the glossary term, not a synonym. Care Plan, not Recommendations. Health Log, not History. Advisories, not Alerts.

### Preferred terms

| Use | Avoid |
|---|---|
| Farmer | User, customer, account |
| Crop | Plant, produce |
| Scan | Capture, upload, check |
| Diagnosis | Prediction, detection |
| Care Plan | Recommendations, tips |
| Health Log | History |
| Advisories | Alerts, notifications |
| Field Calendar | Crop calendar, planner |
| Agri Shop | Marketplace |
| Agri Pro | Premium |
| Cooperative | Coop, enterprise |
| Partner Offer | Ad, sponsored product |

- Headline: short, specific.
- Body: one sentence explaining why the screen is empty.
- Action: one clear next step.

- EN: "No scans yet. Your first diagnosis starts here."

- CEB: "Wala pa'y scan. Dinhi magsugod ang imong unang diagnosis."

## 15. Numbers, dates, and currency

- Dates: locale-aware, for example `12 Nov 2026` in English.
- Time: 12-hour format with AM/PM for the Philippines.
- Currency: `PHP` and `P` symbol; use locale-aware formatting.
- Confidence: whole percent, for example `92%`; never imply certainty.
- Temperature: Celsius, one decimal only when useful.
- Use tabular numerals in data contexts.
- Keep placeholder order stable across languages.

## 16. Review workflow

1. English source is approved by product.
2. Translations are drafted by a native speaker, not a machine alone.
3. A second native reviewer checks tone and farming vocabulary.
4. Screenshots are reviewed at 200% text scale.
5. Placeholders and plural forms are tested.
6. Approved strings move from "draft" to "reviewed" in this document.
